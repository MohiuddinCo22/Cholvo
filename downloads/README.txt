Put the APK files here, with EXACTLY these names:
  cholvo-merchant.apk   (Merchant app)
  cholvo-rider.apk      (Rider app)
Uploading a new file with the same name replaces the old one. Cloudflare Pages allows files up to 25 MB.
If an APK is bigger than 25 MB, host it elsewhere (for example a GitHub Release) and paste its direct link into "apkUrl" in app-update.json.
